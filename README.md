# Noel N. Cobangbang

Next.js profile site for Noel N. Cobangbang, an AYS Neopreneur.

## Local development

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```powershell
npm run build
npm start
```

The repository uses the Next.js App Router and is ready to import into Vercel.
